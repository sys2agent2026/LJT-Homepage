# Junteng Liu — Personal Homepage

Personal academic homepage of [Junteng Liu](https://sys2agent2026.github.io/LJT-Homepage/), a first-year PhD candidate at the HKUST NLP Group, advised by Professor Junxian He. Research focuses on natural language processing and machine learning.

Built with the [Academic Pages](https://github.com/academicpages/academicpages.github.io) template, which was forked from the [Minimal Mistakes Jekyll Theme](https://mmistakes.github.io/minimal-mistakes/).

## Local development

1. Install dependencies: `bundle install`
1. Serve the site locally: `jekyll serve -l -H localhost`
1. Open <http://localhost:4000/LJT-Homepage/>

A Dockerfile and a devcontainer configuration are also included if you prefer not to
install Ruby tooling locally.
